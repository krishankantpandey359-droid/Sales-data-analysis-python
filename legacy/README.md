# Preserved original sales analysis

This folder retains the original six-row regional/product sales analysis while the repository root contains the expanded Walmart weekly-sales project.

Run from the repository root:

```bash
python legacy/project.py --data legacy/sales_data.csv --save-chart outputs/legacy-sales-by-region.png
```

The original dataset contains six illustrative records. Its totals are useful for reproducing the original exercise, not for drawing market-level conclusions.
